# Existing allocations: recommended review, no silent rewriting

All 26 original exercise records, including coefficients and IDs, are unchanged. The following are **proposed bookkeeping revisions**, not scientifically measured exact values. A value of 0 means omit that muscle from `contributions`. They would change source/default-plan totals, so they are recommendations for a future separately approved model revision. New catalog rows already use the conservative principles below where appropriate.

| Existing ID / exercise | Retained value | Recommended candidate | Basis and uncertainty |
|---|---|---|---|
| `source-22` Leg Press | Hamstrings 0.5 | **0** | Remove automatic knee/hip co-contraction credit. Squat longitudinal evidence (`squat`, `hip-thrust`) shows little hamstring growth; application to supported leg press is indirect, so moderate confidence in conservative omission, not proof of no stimulus. |
| `source-41` Hack Squat | Hamstrings 0.5 | **0** | Same rationale, with machine/stance dependence. Quads 1, glute max 0.5, adductors 0.25 can remain as conservative calibration. |
| `source-43` Lunges | Hamstrings 0.5; Glute med/min 0.5 | **0; 0** | Avoid assigning group credit solely for co-contraction or frontal-plane stabilization. Actual long-stride loading can differ. Retain quads 1 and glute max 1 only when the movement includes meaningful deep knee/hip extension; use separately defined variants otherwise. Evidence is indirect. |
| `source-21` RDL | Erector Spinae 0.5 | **0** for a neutral-spine hip-hinge entry | Bracing is not automatically equivalent to direct spinal-extension work. This is a conservative accounting choice, not a claim isometrics cannot grow muscle. `lumbar` and `lumbar-counter` show technique/device specificity and uncertainty. |
| `source-40` 45° Hip Extension | Hamstrings 0.5; Glute max 0.5; Adductors 0.25; Erector Spinae 0.5; no full-credit group | **Hamstrings 1, Glute max 0.5, Adductors 0.25, Erector Spinae 0** for a soft-knee neutral-spine hinge | Requires narrowly defining hip rather than spinal extension. If deliberate spinal extension is intended, use the separate spinal-extension entry instead. The source label alone cannot settle which version the owner intended. Low confidence. |
| `source-30` Wide-Grip Seated Cable Rows | Lats 1; grouped retractors 0.5; rear delts 0.5; biceps 0.5 | **Lats 0.25; grouped retractors 1; rear delts 0.5; biceps 0.5** for elbows flared 60–90° with deliberate scapular retraction | Joint-action inference (`anatomy-upper`), not longitudinal validation of these exact fractions. A wide hand grip with tucked elbows should not inherit this revision automatically. |
| `source-25` Standing Calf Raise | Soleus 0.5 | **1 is a plausible future alternative**, retain 0.5 pending model revision | `calf` found similar soleus growth in standing and seated training. This weakens a universal half-credit assumption, but does not establish an exact 1:1 set equivalence for every setup. New straight-knee variants retain the source's conservative 0.5 for consistency. |
| `source-5`, `source-6`, `source-34` presses | Triceps 0.25 | **Retain 0.25**; 0.5 is plausible but not established for every press | `press` supports triceps growth; `volume` supports fractional accounting overall. Neither determines 0.25 versus 0.5 for a particular grip/depth/person. Close-grip triceps-focused variants have separately defined credits. |
| `source-8`, `source-14` vertical pulls | Rear Delts 0.25 | **0 for narrowly defined standard vertical pulling** | Posterior-deltoid role is technique-dependent and is not automatically a meaningful weekly-volume stimulus. New vertical pulls omit it; retained originals remain flagged for review. |
| `source-10` Hammer Curls; `source-9`, `source-35` supinated curls | Partition among biceps, brachialis and brachioradialis | **Retain the source bins provisionally** | `elbow` establishes position-dependent moment arms, not a validated hypertrophy split. Reverse curls are low-confidence anatomical mappings; grip changes do not justify spurious decimals. |

Do not multiply a coefficient by a reported hypertrophy ratio from a between-exercise trial. Different regional sampling, populations, loading, proximity to failure and measurement error make that conversion unjustified. No evidence reviewed here warrants expanding the app's allowed coefficient values to fine decimals. Preserve 1/0.5/0.25; use absent credit for 0, and make changes exercise-specific and versioned.

The calf comparison is [Kinoshita et al., 2023](https://pubmed.ncbi.nlm.nih.gov/38156065/); the squat depth evidence is [Kubo et al., 2019](https://pubmed.ncbi.nlm.nih.gov/31230110/); the direct/indirect dose synthesis is [Pelland et al., 2026](https://pubmed.ncbi.nlm.nih.gov/41343037/). Full bibliographic details and limitations are in `sources.csv`.
