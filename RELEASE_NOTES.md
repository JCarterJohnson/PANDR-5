# PANDR-5 0.1.0 preview

First downloadable preview of the PANDR-5 training app. Includes source-derived progression, constrained/custom planning, fractional muscle volume, set logging, recovery check-ins, history, full CSV export, and JSON backups.

**This preview saves on each device. Live cloud accounts are not yet configured.** Account integration is present in the source and can be enabled after a free backend is provisioned. Keep JSON backups to move training between devices.

The exercise library includes only the existing spreadsheet’s movements. The owner’s expanded dataset will be added later.

Desktop packages are unsigned; operating systems may show security warnings. Windows and Linux packages are built in CI; runtime checks on those operating systems have not yet been performed. Mobile uses the installable web app.
